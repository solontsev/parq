# parq
A blazingly-fast terminal tool for exploring and analyzing Apache Parquet files: inspect schemas, view statistics, browse data, and dissect structures.

## Installation

```bash
# From PyPI
cargo install parq
```

## Usage

```bash
parq path/to/parquet/file.parquet
```
